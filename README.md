# Marstek Venus E 3.0 offer page

Landing page for `https://marstekenergy.ph/venus-e-3-offer`.

## Files

- `venus-e-3-offer/index.html` - the whole page (styles, fonts and scripts are inside it)
- `venus-e-3-offer/img/` - the page's images

## Uploading

Upload the `venus-e-3-offer` folder to the root of the website, keeping the folder name.
The page must open at `/venus-e-3-offer` and its images at `/venus-e-3-offer/img/`.
Nothing else on the site needs to change.

## Before it goes live

- The "Privacy Policy" text has no link yet.
- No Meta pixel, Google Analytics or Google Ads IDs are set yet.

Both are built into `index.html`, so a new copy of the file will be supplied once they are known.
Do not edit `index.html` by hand.
